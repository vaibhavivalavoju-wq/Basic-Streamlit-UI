# Basic-Streamlit-UI
## Description

The Language Translation Tool is a simple web application built using Streamlit that allows users to enter text, select source and target languages, and translate text between different languages. The project provides an interactive and user-friendly interface for language translation and can be integrated with translation APIs such as Google Translate.

## Features

* Enter text for translation
* Select source language
* Select target language
* Translate text with a single click
* Clean and responsive user interface
* Ready for integration with translation APIs

## Technologies Used

* Python
* Streamlit

## Installation

```bash
pip install streamlit
```

## Run the Application

```bash
python -m streamlit run app.py
```

## How It Works

1. Enter the text to be translated.
2. Choose the source language.
3. Choose the target language.
4. Click the **Translate** button.
5. View the translated text in the output section.
